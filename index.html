SafeVision — AI+WebAR Predictive Safety

Web demo: uses your webcam + TensorFlow.js object detection to simulate hazard alerts and AR overlays.

How this demo works

  1. Loads a pre-trained COCO-SSD model (TensorFlow.js) in browser.
  2. Runs real-time detection on webcam frames.
  3. If certain classes (e.g., person, bicycle, car) are detected close, it shows AR-style warnings and predictive alert boxes.

Note: This is a prototype/demo — replace COCO-SSD with a domain-specific hazard model for production.
